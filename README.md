# 🍽️ Food Management System

The **Food Management System** is a backend application built using **Node.js** and **Express.js**, designed to manage food items efficiently. It allows an **admin** to **add, update, and delete food items** using a REST API. The system uses **MySQL** for data storage.

## 🚀 Features

- 🥗 **Add Food Items** – Admin can add new food items with details like name, category, price, and availability.
- 📝 **Update Food Items** – Modify existing food item details.
- ❌ **Delete Food Items** – Remove food items from the database.
- 📦 **REST API** – Built with Express.js for structured API endpoints.
- 🛢 **Database Support** – Uses **MySQL** for reliable data storage.

## 🏗 Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **API Testing:** Postman
